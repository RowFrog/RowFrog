The app must show these credits wherever their data appears.

| Deutscher Wetterdienst (DWD), GeoServer maps.dwd.de | Lake warnings (Binnenseen) and weather warnings per municipality | CC BY 4.0 | "Deutscher Wetterdienst" |
| OpenStreetMap | Lake outlines for the wave calculation; club positions (Nominatim geocoding) | ODbL | "© OpenStreetMap contributors" |
| Deutscher Ruderverband e.V. (rudern.de) | Club list in the search: names, short names, website, boathouse address, kinds of rowing | No open licence; imported with the owner's OK, permission to be asked | "Deutscher Ruderverband e.V." |
| GKD Bayern (Bayerisches Landesamt für Umwelt) | Lake water temperature | CC BY 4.0 | "Gewässerkundlicher Dienst Bayern" |
| Copernicus Land Monitoring Service | Lake ice extent (planned) | Copernicus data policy | "Copernicus Land Monitoring Service" |
| Windy Webcams API | Webcam images (planned) | Windy API terms | Windy credit and a link on every image |

If the app ever has ads or subscriptions, the Open-Meteo free tier no longer
applies: switch to a paid Open-Meteo plan or load DWD open data directly.
