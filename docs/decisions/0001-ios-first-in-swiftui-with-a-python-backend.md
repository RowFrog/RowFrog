# 1. iOS first, in SwiftUI, with a Python backend

- Date: 2026-10-18
- Status: decided (owner)
- Where: `ios/`, `backend/`

## Decision

Build the iPhone app first, natively in SwiftUI. A small Python backend gathers the weather, computes waves and the rowing light, and serves the results. Android comes later.

## Why

Part of the first plan (MVP plan, 2026-10-18). A native app gives widgets and the look of Apple's Weather app, which the UI follows. The backend does the heavy work once for every user.
