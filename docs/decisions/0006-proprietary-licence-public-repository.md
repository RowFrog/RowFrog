# 6. Proprietary licence, public repository

- Date: 2026-10-18
- Status: decided (owner)
- Where: `LICENSE`

## Decision

The code is "all rights reserved". The repository stays public.

## Why

Most rights for an App Store app; a public repository gets free GitHub Actions minutes, including macOS runners.

## Turned down

An open-source licence; a private repository (paid macOS minutes).
